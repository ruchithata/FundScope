# FundScope

**FundScope** is an evidence-first public finance explorer that helps users understand how government spending is distributed across states, sectors, and time.

The platform combines structured government spending data with official budget, policy, and audit documents to provide **transparent, source-backed insights** into public expenditure.

## Features

* **Government Spending Explorer** — Explore public expenditure across states, sectors, and financial years.
* **Spending Trends** — Analyze how government spending changes over time.
* **State & Sector Comparison** — Compare expenditure across different states and sectors.
* **Evidence-First Insights** — Numerical results are derived from structured datasets rather than generated by an AI model.
* **Official Document Search** — Search government budget, policy, and audit documents using semantic search.
* **Source Transparency** — Display the source, methodology, and data-quality information behind insights.
* **AI-Assisted Explanations** — Convert retrieved financial information into understandable explanations while grounding responses in available evidence.
* **Anomaly Detection** — Identify unusual spending patterns and statistical spikes without interpreting them as evidence of wrongdoing.
* **Data Quality Indicators** — Surface information about data completeness, reliability, and methodology.
* **CSV Export** — Export analyzed spending data for further use.

## How It Works

FundScope separates **numerical truth** from **documentary context**.

```text
Government Data
      │
      ▼
Data Cleaning & Processing
      │
      ▼
PostgreSQL
      │
      ├──────────────► Analytics & Comparisons
      │
      └──────────────► Spending Dashboard
                           
Official Documents
      │
      ▼
Text Extraction & Chunking
      │
      ▼
Embeddings
      │
      ▼
Chroma Vector Database
      │
      ▼
Semantic Search
      │
      ▼
Evidence-backed AI Explanation
```

Structured government datasets are used as the source of numerical values, while official documents provide policy, budget, audit, and methodological context.

The AI layer does not act as the source of official financial figures. It works with retrieved and calculated information to help users understand the results.

## Running Locally

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

Create and activate a Python virtual environment:

```bash
cd backend
python -m venv venv
source venv/Scripts/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the FastAPI server:

```bash
uvicorn app.main:app --reload
```

## Data Sources

FundScope is designed to work with **official Indian government sources**, including:

* Reserve Bank of India
* Government of India Open Government Data Platform
* Ministry and department budget documents
* Official government statistical datasets
* Government policy and audit publications

Each dataset and document is intended to retain its original source information so that users can trace insights back to official evidence.

## Data & AI Principles

FundScope follows several principles when presenting public-finance information:

1. **Numbers come from structured data.**
2. **Official documents provide context and supporting evidence.**
3. **AI does not invent or estimate official figures.**
4. **Sources and methodology should remain visible to users.**
5. **Statistical anomalies are not automatically treated as wrongdoing.**
6. **Observational spending data is not presented as proof of causal relationships.**

## Project Goals

FundScope aims to make public-finance data more accessible by combining data exploration, statistical analysis, document retrieval, and AI-assisted explanation into a single transparent platform.

The goal is not simply to show government spending numbers, but to help users understand **what was spent, where it was spent, how it changed, and what official evidence provides context for those numbers**.
